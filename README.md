# Каталог портативных электростанций

Статичный сайт: `index.html` + папки `img/` и `fonts/`. Загружать нужно все три вместе.

## Как поменять цену
Откройте `index.html`, найдите блок `const PRICES`, впишите цену числом после кода модели:

    "A-1800": 59990,

Если стоит 0, на сайте показывается «Цена по запросу». Валюта, подписи и кнопка связи меняются в блоке `SETTINGS` (там же, выше).

## Как выложить на GitHub Pages
1. Создайте репозиторий и загрузите в корень `index.html`, `img/`, `fonts/`.
2. Settings → Pages → Branch: main, папка / (root) → Save.
3. Через минуту сайт откроется по адресу https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
